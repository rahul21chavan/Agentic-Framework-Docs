# Agentic Framework Docs

A documentation repository containing reference materials for agent-based parsing and migration design.

## Contents

- [`Parsing_Agent_Specification.docx`](./Parsing_Agent_Specification.docx) — Agent parsing specification document.
- [`SAS_to_Snowflake_Whitepaper.pdf`](./SAS_to_Snowflake_Whitepaper.pdf) — Technical whitepaper covering migration from SAS to Snowflake.

## Overview

This repository brings together two technical documents:

1. **Parsing Agent Specification** — describes requirements or design considerations for an agent responsible for parsing information.
2. **SAS to Snowflake Whitepaper** — provides material about moving SAS workloads or assets to the Snowflake data platform.

## Usage

Open each file using a compatible application:

- Microsoft Word or a DOCX-compatible editor for `Parsing_Agent_Specification.docx`
- A PDF reader for `SAS_to_Snowflake_Whitepaper.pdf`
